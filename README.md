# Android Engineering Career Roadmap

Interactive roadmap for Junior to Senior Android engineers.

## Features
- Foundations, Architecture, Advanced Engineering, Professional Growth
- Path to Senior toggle
- Progress tracker with localStorage
- Print-ready checklist page
- SEO metadata, robots, sitemap

## Tech Stack
- Next.js 15
- React 18
- Tailwind CSS
- Static export hosting

## Setup

```bash
npm install
npm run dev
